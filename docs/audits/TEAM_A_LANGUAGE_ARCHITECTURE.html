The five categories

These are the distinctions that made the copy write itself. Each string was assigned one category first; the wording followed.

CategoryQuestion it answersVocabularyThe distinction that matters
ACTIONWhat do I do here? Add context · Update context · Give Barry context Varies with state. Nothing yet → Add. Something already there → Update. Mission Control's CTA now switches on reconCompletion rather than saying one thing forever.
KNOWLEDGEWhat does Barry have? What Barry Knows The destination and the readout. Never the act of providing it.
COVERAGEHow much has been provided? Context complete · Context Coverage · Areas Covered · No context yet A proportion. "Fully trained" was always coverage wearing a training word.
FRESHNESSHow current is it? Context last updated {n} days ago · Outdated Not coverage. "Last trained 90 days ago" is about recency, so "last context 90 days ago" would be nonsense. This was the category most easily got wrong.
SOURCEWhere did this output come from? Using your RECON context · Barry is using your context for this dimension Attribution on generated output. Distinct from coverage — it says this specific thing drew on your context.
STATUSWhat state is this in? Covered · Thin data · Outdated · Conflict Rewritten per state rather than as one word. "Trained" as a legend entry became Covered; as a tile title it became — Covered.

One rule fell out of the exercise and is worth keeping: the user provides context; Barry uses it. Every string where the product was the subject of a learning verb became a string where the user is the subject of a giving verb, or Barry is the subject of a using verb. Nothing in the vocabulary now implies the system changes itself.
